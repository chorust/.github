# Chorust

**Chorust 中文介绍 / Chinese README**

[English](README.md)

Chorust is an open-source organization for composable systems, data, and AI infrastructure, with Rust at the core.

## Projects / 项目

- [Chorust](https://github.com/chorust/chorust) — Local-first coding-agent observability and control.
- [Radiust](https://github.com/chorust/radiust) — Radar data acquisition and processing infrastructure.
- [DuckJeu](https://github.com/chorust/duckjeu) — Judgment as a SQL primitive for DuckDB.
- [DuckOMo](https://github.com/chorust/duckomo) — Direct Open-Meteo OM querying from DuckDB.
- [Conductorust](https://github.com/chorust/conductorust) — Spec compiler, early-stage.

## Principles / 设计原则

- Focused
- Composable
- Explicit
- Local-first where possible
- Evidence-driven
- Rust at the core
